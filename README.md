I am Dana Khaing, a First Class Honours Computer Science graduate from Royal Holloway, University of London.

I enjoy building practical products across the full stack, from interactive frontend experiences to backend systems, realtime features, and data-driven workflows. My GitHub is a mix of product work, portfolio experiments, university projects, and learning projects that show how my work has evolved over time.

## Featured Projects

### FlowBit
[FlowBit_Capacity-Based-Numeric-Transaction-Management-System](https://github.com/dana-khaing/FlowBit_Capacity-Based-Numeric-Transaction-Management-System)

A realtime operations platform for capacity-based numeric transactions. Built with a Next.js frontend and a Django backend, with admin workflows, lucky draw management, notifications, reporting, and live updates across sessions.

### RPG Portfolio
[Portfolio](https://github.com/dana-khaing/Portfolio) | [Live Site](https://dana-khaing.github.io/Portfolio/)

A portfolio website designed as an RPG character status screen. Built with React, TypeScript, Tailwind CSS, Vite, and Framer Motion, with game-inspired UI, animated stat bars, and live GitHub-powered profile data.

### KUMA Social Media
[KUMA_SocialMedia](https://github.com/dana-khaing/KUMA_SocialMedia)

A final year project focused on building a social platform for the Royal Holloway community to connect, discuss topics, and share knowledge.

### PhoneSine Mobile E-Commerce
[PhoneSine-MobileEcommerce](https://github.com/dana-khaing/PhoneSine-MobileEcommerce)

A marketplace project for browsing devices, filtering by category and price, and supporting shopping and payment-oriented flows.
