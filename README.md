## Hello, I am Dana

I am a software engineer and full-stack developer with a **First Class Honours BSc in Computer Science** from **Royal Holloway, University of London**.

I build product-focused software across web, mobile, backend, realtime, and offline-first systems. My recent work includes a Phoenix LiveView booking platform, an offline-first point-of-sale system, a React Native workout tracker, a creator-first streaming platform, and production-oriented ecommerce and operations tools.

- Based in Isleworth, UK
- Interested in full-stack, mobile, distributed product workflows, developer tooling, and applied AI
- Comfortable taking products from data model and API design through accessible interfaces, testing, CI, and deployment
